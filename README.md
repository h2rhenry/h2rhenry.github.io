## Giới thiệu

Trang web tĩnh giới thiệu kỹ năng, kinh nghiệm làm việc và các dự án Skript / Java của **h2rhenry**. Trang viết bằng HTML, CSS và JavaScript thuần, không cần bước build, có thể đưa thẳng lên GitHub Pages.

## Tính năng

| Tính năng | Mô tả |
| --- | --- |
| **Sáng / Tối** | Lần đầu truy cập luôn ở chế độ tối. Lựa chọn sau đó được ghi nhớ và đồng bộ giữa các tab và trang (`js/theme.js`). |
| **Hai ngôn ngữ** | Việt / Anh, lưu lại cho lần sau. Lần đầu, trang dùng ipwho.is để chọn ngôn ngữ mặc định. |
| **Trạng thái Discord** | Hiển thị online, trò chơi đang chơi và bài hát Spotify đang nghe, lấy qua Lanyard API. |
| **Trình phát nhạc** | Phát nhạc có sẵn trong `assets/music`, có tua, âm lượng và ảnh bìa. |
| **Bộ đếm lượt truy cập** | Có dự phòng lưu cục bộ khi dịch vụ đếm không phản hồi. |
| **Hiệu ứng động** | Chữ gõ luân phiên chức danh, nội dung hiện dần khi cuộn, thanh kỹ năng chạy, thẻ nhích nhẹ khi di chuột. |
| **PWA** | Có `manifest.json` và service worker, cài được lên màn hình chính. |
| **Study Corner** | Các trang học tập ẩn, mở bằng **Ctrl + Alt + Shift** trên máy tính hoặc nút chấm ẩn trên điện thoại. |
| **Máy tính Casio fx-580VN X** | Lớp phủ mô phỏng, bật bằng **Ctrl + Alt + C** trong các trang Study Corner. |
| **Truy cập tốt** | Liên kết bỏ qua nội dung, viền focus, nhãn ARIA, vùng chạm đủ lớn và tôn trọng chế độ giảm chuyển động. |

## Bắt đầu nhanh

Service worker cần chạy qua máy chủ HTTP, không mở trực tiếp bằng `file://`.

```bash
git clone https://github.com/h2rhenry/h2rhenry.github.io.git
cd h2rhenry.github.io

python3 -m http.server 8000     # hoặc: npx serve .
```

Mở `http://localhost:8000`. Để triển khai, đẩy lên nhánh `main` của repo `<tên>.github.io` và bật GitHub Pages.

## Tùy chỉnh

<details>
<summary><b>Màu sắc và chế độ mặc định</b></summary>

- Màu nằm ở các biến `:root` cuối `css/style.css` (`--bg-main`, `--surface`, `--accent-cyan`, `--text-main`...). Chế độ sáng được ghi đè trong `:root[data-theme="light"]`.
- Chế độ mặc định cho người truy cập lần đầu đặt trong `js/theme.js`, dòng `R.dataset.theme = read() || 'dark'`.

</details>

<details>
<summary><b>Tài khoản Discord</b></summary>

Đổi `DISCORD_USER_ID` trong `js/main.js`. Tài khoản cần tham gia máy chủ Discord của Lanyard để nhận được trạng thái.

</details>

<details>
<summary><b>Thêm bài hát vào playlist</b></summary>

1. Chép file `.mp3` vào `assets/music/` (tên không dấu, không khoảng trắng).
2. (Tùy chọn) Chép ảnh bìa vào `assets/music/covers/`.
3. Thêm một dòng vào mảng `PLAYLIST` trong `js/main.js`:

```js
{ title: 'Tên bài', artist: 'Tên ca sĩ', src: 'ten-bai.mp3', cover: '3.webp' },
```

</details>

<details>
<summary><b>Chức danh gõ chữ, trang ẩn, cache</b></summary>

- Chức danh gõ luân phiên: sửa `data-roles` ở `index.html`, các chức danh cách nhau bằng `|`.
- Thêm trang ẩn: thêm một object vào mảng `HIDDEN_PAGES` trong `js/main.js`.
- Sau khi cập nhật file, tăng `CACHE_VERSION` trong `sw.js` và số `?v=` của file CSS/JS để người đã truy cập thấy bản mới.

</details>
